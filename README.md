# EE ENG Practice

Practice site built from the six PDFs in `Assets/PDF`:

| Section | What it contains | Source |
|---|---|---|
| Grammar patterns | 18 topics: tenses, modals, passive, agreement, connectors, adjective/adverb, non-finite verbs, if-clauses, error-identification checklist and more | Grammar sheet, guide, simulation |
| Vocabulary | 223 items, English + Burmese, list / flashcards / quiz | Vocab sheet |
| Reading | 5 passages, 39 questions, glossary with Burmese, Burmese summary, explained answers | Guide + Simulation 001 |
| Listening | 2 conversations, 2 talks, 7 speaking items, read aloud with the browser voice | Guide |
| Grammar practice | 193 items (incomplete sentence, error identification, text completion) | Grammar sheet, guide, simulation |

Open `index.html` through any static web server (for example `python -m http.server`). Progress is saved in the browser (localStorage).
Font: DM Sans (Noto Sans Myanmar for Burmese text).
